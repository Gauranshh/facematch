# Changelog

## 3.0.0
- Accounts: admin and member roles, invite links, per-folder access, view-only members, audit log.
- Instant detection of new, changed and deleted photos (filesystem watcher with polling fallback).
- Private people per user, with a shared "discovered" pool; naming someone never affects other users.
- Expiring, revocable share links with a public viewer page.
- Themes: six accent palettes in light, dark or automatic mode, saved per user.
- Admin overview with library statistics, disk usage and activity log.
- Hardened deployment: non-root Docker image with health check, systemd unit, HTTPS proxy example, CI on Linux/Windows/macOS.

## 2.0.0
- Persistent index, instant search at any library size, ArcFace "accurate" model, people discovery, filters, feedback learning.

## 1.0.0
- First version: upload a face, copy matching photos.
